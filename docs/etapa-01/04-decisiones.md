## Decisiones tomadas como equipo

Como equipo decidimos desarrollar un proyecto de base de datos orientado a una tienda de venta de artículos para tomar mate.

Elegimos esta temática porque nos permite trabajar con diferentes entidades y relaciones, como clientes, productos, proveedores, pedidos y detalles de pedidos, aplicando los conceptos de modelado, normalización y diseño de bases de datos vistos durante la materia.

Además, decidimos mantener el alcance del proyecto centrado en la gestión de ventas físicas, sin incorporar funcionalidades que no sean necesarias para los objetivos planteados.
