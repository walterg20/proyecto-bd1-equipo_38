## 1. Aporte realizado
- Redacción del documento formal de Reglas de Negocio para el sistema de la tienda de Matiensos.
- Documenté las validaciones centrales del negocio en `docs/etapa-01/reglas_de_negocio.md`.

## 2. Decisiones en las que participé
- Acordamos que toda venta debe tener un cliente asociado, usando "Consumidor Final" para ventas rápidas.
- Decidimos que no se puede registrar una venta si el producto no tiene stock disponible.
- Definimos precio: DECIMAL - Precio de venta actual del producto al momento de la consulta.

## 3. Problemas o dificultades identificadas
- Dificultad grupal para diferenciar una Regla de Negocio de una Restricción de base de datos, de una Regla de Dominio y de una Funcionalidad del sistema. Nos pasaba que redactábamos acciones del software, validaciones técnicas o condiciones sobre los valores de un dato confundiéndolas con verdaderas reglas de negocio.

## 4. Soluciones o propuestas realizadas
- Propuse usar como filtro la pregunta: "¿Esto es una condición que el negocio impone pase lo que pase?". Si la respuesta era sí, era Regla de Negocio. Si era "el sistema debe hacer...", era Funcionalidad.
